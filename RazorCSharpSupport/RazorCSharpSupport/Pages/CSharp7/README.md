# CSharp 7 features

Source: https://devblogs.microsoft.com/dotnet/new-features-in-c-7-0/

## New features in C# 7

- Out variables  
- Tuples  
- Pattern matching  
- Local functions  
- Ref returns and ref locals  
- Expression-bodied members  
- Throw expressions  
- Generalized async return types  
- Discards
